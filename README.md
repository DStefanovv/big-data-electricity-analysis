# Анализ на електропотреблението

Проект по дисциплина „Големи данни“, Вариант 1.

Целта на проекта е да се генерира и анализира голям набор от синтетични данни за почасово потребление на електроенергия. Анализът е описателен и показва основни зависимости по месеци, часове, региони и тип тарифа.

## Данни

Съдържание:

- **1 051 200 записа**;
- **120 домакинства**;
- **12 български града** в 6 региона;
- почасови измервания за периода 01.01.2025 – 31.12.2025 г.;
- дневна и нощна тарифа;
- данни за потребление, температура, соларно производство и цена.

Данните са синтетични и се създават от проекта. Големите CSV и Parquet файлове не са включени в GitHub, защото могат да бъдат генерирани отново чрез предоставените скриптове.

## Използвани библиотеки

- **Faker** – създаване на синтетични профили на домакинствата;
- **Dask** – проверка, почистване, обогатяване и запис в Parquet;
- **PySpark** – описателен анализ и агрегиране на резултатите;
- **Ray** – паралелен анализ на шестте региона.

NumPy и Pandas се използват за по-бързо генериране на числовите стойности.

## Стартиране на анализа

Необходими са:

- Python 3.12;
- Java 17;
- Node.js и npm.

Създаване на виртуална среда и инсталиране на библиотеките:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe check_environment.py
```

Изпълнение на отделните стъпки:

```powershell
.\.venv\Scripts\python.exe src\generate_data.py
.\.venv\Scripts\python.exe src\validate_dataset.py
.\.venv\Scripts\python.exe src\process_with_dask.py
.\.venv\Scripts\python.exe src\analyze_with_pyspark.py
.\.venv\Scripts\python.exe src\analyze_with_ray.py
```

## HTML отчет

Отчетът е разработен с React и Vite. Той зарежда готовите JSON резултати от папката `web/public/data`.

Стартиране:

```powershell
cd web
npm install
npm run build
npm run preview
```

След стартиране отчетът е достъпен на адрес:

```text
http://127.0.0.1:4173/
```

Файлът `dist/index.html` не трябва да се отваря директно, защото React приложението трябва да работи през локален уеб сървър.

## Визуализации

HTML отчетът съдържа четири основни визуализации:

1. месечно потребление на електроенергия;
2. среден почасов профил;
3. потребление по региони;
4. сравнение между дневна и нощна тарифа.

Отчетът показва също броя обработени записи, измерените времена и кратки автоматично генерирани изводи.

## Основни резултати

- Обработени записи: **1 051 200**
- Общо потребление: **405,5 MWh**
- Енергия от мрежата: **367,2 MWh**
- Обща изчислена цена: **42 274,25 €**
- Оценени соларни спестявания: **4 888,05 €**
- Най-високо месечно потребление: **януари**
- Най-висок среден почасов товар: **около 21:00 ч.**

Цените са преобразувани в евро за добиване на по-ясна представа на данните и цените.

## Време за изпълнение

| Операция | Библиотека | Време |
|---|---|---:|
| Генериране на данните | Faker | 12,64 сек. |
| Обработка и запис в Parquet | Dask | 8,56 сек. |
| Описателен анализ | PySpark | 25,40 сек. |
| Регионален анализ | Ray | 10,50 сек. |

Общото измерено време е приблизително **57,11 секунди**. Ray изпълнява шест регионални задачи, като самото паралелно изчисление отнема 1,70 секунди.

## Кратки изводи

- Най-високото потребление от мрежата е през януари.
- Най-високото средно почасово потребление е около 21:00 ч.
- Югозападният регион има най-високо годишно потребление от мрежата на домакинство.
- Домакинствата със соларни панели използват средно с 25,8% по-малко електроенергия от мрежата.
